> 身体部位需要单独钩织出来缝合

### 图解卡转录（`_img/030-mifei-ruantang/img03.jpg`，手写体逐行）

```
Head
R1: 6X
R2: 6V
R3: 6(X, V)
R4: 6(X, V, X)
R5-7: 24X
R8: 6(X, A, X)
R9: 6(X, A)

Body
R10(FLO): 6(X, V)
R11-13: 18X
R14: 6(X, A)
R15: 6A
```

卡片左侧另有三个小件标注（原文未区分耳/手/脚，照录）：

```
R1-4: 8X
R1-3: 6X
R1-3: 8X
```

（即：起 8X/6X/8X 的螺旋直筒小件，对应米菲的两耳、两手、两脚中的三种规格；黑线绣 X 形嘴与两点眼。）

### 体系互证

Head R1 6X→R9 6(X,A) 收口 + Body 以 R10(FLO) 加针接出，是软糖体「头身分钩、半针对接」的迷你挂件版；与 001/029 的 5X 开面主体不同，本款为 6X 起全圆头（无开面），属软糖体家族的小尺寸变体。
