## 正文（原样转录）

> 之前做了一款暴力熊钩织的教程，很多盆友都喜欢，然后又进行了改良，做了一款迷你版的暴力熊，比正常的小一个型号，但是更可爱了。
> 这个小熊比较简单，一共有头部、身体、四肢、耳朵组成。我们从上往下钩织。

### 头部（环形起针）

```
R1--6---6X，环形起针
R2--12--6V
R3--18--（X,V）6
R4--24--（2X,V）6
R5-R8--24--24X
R9--33--3X,（V,X）4,(X,V)5,3X
R10--42--3X,（V,2X）4,(2X,V)5,3X
R11--42--42X
R12--33--3X,（A,2X）4,(2X,A)5,3X
R13-R14--33--33X
R15--25--(A,2X)8,X
R16--13--X,12A
```

### 身体

```
R1--6--6X，环形起针
R2--12--6V
R3--18--（X,V）6
R4--24--（2X,V）6
R5-R6--24--24X        （原文「2424X」为排版粘连，已拆开照录）
R7--18--(A,2X)6
R8-R10--18--18X
R11--12--(A,X)6
```

### 胳膊（×2）

```
R1--6--6X，环形起针
R2--9--(X,V)3
R3-R4--9--9X
R5--6--(A,X)3
R6-R8--6--6X
```

### 腿（×2）

```
R1--6--6X，环形起针
R2--12--6V
R3--12--12X
R4--8--2X,4A,2X
R5-R8--8--8X
```

### 耳朵（×2）

```
R1--6--6X，环形起针
R2--12--6V
R3--16--（2X,V）4
R4--16--16X
R5--8--8A
```

### 组装（原文）

> 各个部位完成后，在脑袋和身体里面填充棉花或者其他填充物，缝合。
> 耳朵在头部的第 4-7 圈之间；胳膊在身体的第一圈；腿可以按照自己的喜欢缝合，注意两边对称就可以。
> 脖子上，可以找细线打个蝴蝶结，会更有感觉一点，我用的是仿牛皮绳。
> 注意事项：缝合的时候，一定要看好正反面，耳朵、胳膊、腿，一定要对称；填充物建议填饱满一点。
