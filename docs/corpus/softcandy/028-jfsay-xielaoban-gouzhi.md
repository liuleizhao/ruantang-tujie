## 正文

### （1）头和身体（红色、蓝色、白色、黑色、紫色毛线）

```
R1:红色8X
R2:8V
R3:8(X.V)
R4:8(X.V.X)
R5:8(3X.V)
R6-7: 40X
R8:8(2X.V.2X)
R9: 48X
R10:蓝色17X.BLO6X.红色3X.蓝色BLO6X.16X
R11:蓝色23X.白色3X.蓝色22X
R12:蓝色23X.白色A.蓝色23X
R13:蓝色47X
R14:紫色47X
R15:紫色2X.黑色4X.紫色3X.黑色4X.紫色2X.黑色4X.紫色2X.黑色9X.紫色2X.黑色4X.紫色2X.黑色4X.紫色2X.黑色3X
R16-17:紫色47X
R18:7(4X.A).5X
R19:8(3X.A)
R20:两边各12X(中间间隔7针缝合)
R21:12X
R22: 6A
```

衣领: 蓝色R10.FLO(X.T.F.狗牙针.F.T.X)*2

> 作者备注（原文照录）：由于看不懂R20-22钩法，不得不钩完R19断线。按照红色线R1.6X, R2.6V, 换紫色线R3.6V的方法钩织两个蟹脚，第二只脚不断线, 钩4CH连接第一只脚，再钩织一圈32X, 用紫色线与身体缝合。另外，看到网上还有直接从脚往头钩织的方法。

### （2）眼睛*2（红色、白色毛线）

```
R1:红色6X
R2:6(X.V)
R3-9:白色18X
R10:6(X.A)
```

### （3）睫毛*2（黑色毛线）

```
起3CH.SL.X.4CH.SL.2X.3CH.SL.X
```

### （4）手*2（红色、蓝色毛线）

```
R1:红色6X
R2: 6V
R3: 6(X.V)
R4-6.18X
R7:6(X.A)
R8:6A
R9-11:6X
R12:蓝色FLO6V
R13:BLO12X
```

### （5）组装（原文）

用蓝色毛线将胳膊缝合在身体两侧，白色毛线缝合眼睛在头顶位置。粘贴眼睫毛和眼珠。用黑色毛线缝嘴巴和蟹钳分叉，用棕色毛线缝腰部长方形装饰。两个衣领总是翘起来，用蓝色毛线缝在衣服上固定。
