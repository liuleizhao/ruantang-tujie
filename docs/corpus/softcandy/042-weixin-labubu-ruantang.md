### 体系互证

**主体与 001 软糖体通用主体不一致，如实说明**：001/025/035 的软糖体是 `R1:5X → R2:5V → R3:5(x,v) → R4:5(x,v,x) → R5-7:20X → R8:10A`（最大 20 针、R9 外半针+爆米花 B 换色收身）；本条头部为 `环起6X → 最大 42X → R20:6A`（20 圈），是**放大一号的 Q 版一体连钩体**，无爆米花换色，换色靠 `R4:换线`、`R5-R9:换线` 等明文指令完成。相同的是**范式**：环形起针→规律加针→平圈→规律减针、脚+身体连钩并在 R20 留 3X 处接手臂、头套/帽子另钩成"头套件"——与 031 玲娜贝儿「迪士尼通用主体」、033 小哥、036 朵莉亚同属软糖风 Q 版体系。**全文无「软糖」字样**（正文与卡面均未出现），收录理由为：2025 最热潮玩 IP + 完整逐圈图解卡 + 同风格软萌 Q 体，已按语料库惯例在文件与索引内如实标注。
