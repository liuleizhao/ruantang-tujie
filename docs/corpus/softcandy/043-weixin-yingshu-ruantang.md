## 正文（caption/导语，原文）

> 小时候守在电视机前，看英叔腾空踢腿、扶正祛邪，他的笑容总让我安心。长大后重看老片，那份亦庄亦谐的侠气依然动人。于是我想：若把他变成一枚软乎乎的钩织玩偶，该多好？选了米白棉线打底，浅棕勾勒轮廓，用细密短针织出他圆润的脸颊；唐装用深咖色线绣出盘扣与衣纹，连袖口褶皱都藏着细节。最用心的是那抹微笑——嘴角微微上扬，眼神坚定又慈祥，仿佛在说："做人最重要的就是开心。"……这枚软糖般的英叔，不只是玩偶，更是对一个时代的温柔致敬。每次钩针落下，都像在编织一句港式哲理：世界再难，也要笑着面对。

## 图解卡转录（img02：帽子 / 帽饰 / 衣服 / 剑）

```
帽子:黑色
R1:6x
R2:6V
R3:6(X,V)
R4:6(X,V,X)
R5-6:24x
R7:(2X,V,2X)重复3次，后面几针钩短针。（适当加点针，可以更好的戴上去）。
R8:钩X.

帽子上的钩织:R1:起7ch,倒2钩5x,w,4x,粘
R2:v,4x,3v,4x,2v,短线 缝或粘在帽子上面都可以.
再钩一个帽子上的黑布，R1:起7ch倒2钩6x,R2:起立一个ch翻钩6T.
R3-7:来回钩T(长度可以看情况来定)
然后对折起来，在中间的位置拿一股黑线缝一下，一个小房子的黑布条就出来了。
然后拿白色线缝上纹路。
帽子前面的小白布条，是用一股白线钩的，起6ch倒2钩5x,起立1ch钩5x就可以了，
小白布条就出来了，粘在帽子上就可以了。

衣服:衣服的外一共有3排，第一排:头朝下，在左手边入针，钩X,V
第二排:钩中长针，第三排钩长针(就手的周围需要自己去钩织调整)
衣服的袖子是头朝下，在手的一圈都是有针目的，找不到没关系，差不多就可以了，
衣袖上面两针是短袖，下面几针是中长针，这样钩出来的袖子就是上窄下宽。

剑的钩织，用的是61号深棕色(用两股线钩织) 起13ch,用一根铁丝，在铁丝上钩织，
倒2钩sl,x,10t断线，用剩下的线绕线成剑的把柄。剑底用两股线环起6x，
第二圈钩x(起1ch,狗牙针)x,sl,x(起1ch,狗牙针)x,sl一共6针。
剑的绳子起适当的辫子针，在剑上找合适的位置缝上去。
```

### 体系互证

**与 001 软糖体通用主体逐行一致**：`R1:5X → R2:5V → R3:5(X,V) → R4:5(X,V,X) → R5-7:20X → R8:10A`，与 001（jfsay 哪吒/敖丙）、025（啊梨share 素体）、029 敖丙、032 韦一航、033 小哥、035 帕恰狗同一套主体；R9 起 **挑外半针 + B（爆米花针）换色**（灰→肤→白→肤→灰）形成立体脸颊与衣领，R10–R12 收身，正是 001/024/035 的"爆米花换色"标志段。差异：本条 R11 为 `黑色 4X B 3X B 6X`（15 针上直接布 2 个爆米花），比 001 的 R11 少一个爆米花——属角色换色区的正常变体，已照录。头发为片钩梳齿条（6ch/5ch/3ch 倒二回钩），与 033 小哥三层头发的片钩法同族。
