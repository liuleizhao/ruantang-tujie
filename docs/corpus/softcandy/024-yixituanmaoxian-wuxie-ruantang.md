### 图解图片转录（原图见 `_img/024-wuxie-ruantang/02.jpeg`、`03.jpeg`）

**主体**（手写笔记，04.03 17:35，208 字；R 标注原样保留，含换线色提示）

```
R1肤色：环起5X
R2：5v
R3：5（x，v）
R4：5（x，v，x）
R5-R7：20x
R8：10A
R9：换绿色线x，v，B，V，X，V，B，V，X，V
R10：15X，需要完美换线，提前换成浅棕色线
R11：浅棕色线钩4x,B,4x,B,5x
R12：6（X，A）
R13：6A
耳朵：抽两股线，环起4x，不引拔
眼睛：抽两股线缝，缝好后打个死结塞里面
```

（R9/R11 中 B＝爆米花针（5 长针并一针），与既有语料 001 软糖体的 R9/R11 针法同源；行内逗号在原笔记中为中英文混排，按图保留。）

**吴邪头发**（手写笔记，04.05 17:31，244 字）

```
第一层
R1：环起5X
R2:5V（全钩内半针）
R3：6CH，倒2钩5SL，引拔
7CH倒2引拔，钩5X，钩六个
6CH倒2钩5SL，引拔
4CH倒2钩3SL，，钩三个（然后藏线）
第二层
（在留的外半针钩）从耳朵上方入针钩7个CH，6SL在刚才入针的位置钩SL
8CH倒2钩7SL在下一针引拔，钩四个
7CH，到二钩6SL，在同一个针目SL
5CH，4SL，在下一个针目引拔，钩两个（第二个跟第一针的针目引拔）（第二层的每一个辫子可以往下拉一拉，这样更协调）
```

（「7CH，到二钩6SL」的「到二」应为「倒二」，原图笔误按图保留；第一层为环起片钩留外半针，第二层在留下的外半针上钩 CH/SL 发帘，是软糖体头发的典型两层结构。）
