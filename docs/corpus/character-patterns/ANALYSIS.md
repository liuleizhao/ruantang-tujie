## 一、典型人物玩偶图解的部件清单与装配顺序

### 1.1 部件清单（按语料归纳）

| 层级 | 部件 | 说明与语料证据 |
|---|---|---|
| 素体层 | 头 | 球体逐圈；高级写法为"两层头"（内层由身体成型+外包头，防脱落）[005] |
| 素体层 | 身体（躯干+脖） | 中文常"腿→身体→脖子→头"不断线连钩 [006]；英文常头/身分件后缝合 [003][012] |
| 素体层 | 手臂 ×2 | 通常不塞棉、留线尾 [012]；定位到"身体第 N 圈"或"头身接缝两侧" [008][012] |
| 素体层 | 腿 ×2 | 可与身体合并连钩（无裆缝）[006][005]，或独立件缝合 [012] |
| 特征层 | 头发：发帽 + 发片/刘海 | 单独成篇教学 [014]；发帽是所有发片的附着面；发量/重量受结构约束 [005] |
| 特征层 | 五官 | 安全眼（塞棉封口前安装）+ 刺绣嘴/眉 + 色粉腮红（后处理，不进针法）[008] |
| 服装层 | 衣/裙/裤/帽 | 裙可从身体预留外半针直接长出 [005]；`钩离自己远的半针` 留针是中文典型表达 [006 R34] |
| 配件层 | 饰品（耳机、帽耳、盾牌、发饰等） | 图解中列为独立小件，装配说明最简 [005][008] |
| 底模 | Q版素体（base） | 同一素体换色+加发+加配件 = 不同人物 [013] |

**部件总数**：小型人物玩偶一般 8–14 个缝合/连接点级部件（头、身、2 手、2 腿、发帽、5–10 条发片、服装 1–3 件、配件 0–3 件）。

### 1.2 装配顺序（跨语料的公共序）

1. **先织小件**：手、腿（可连身体直接钩上来 [006]）
2. **躯干成型 + 塞棉**：边钩边塞 [003]，收口前完成填充
3. **封头前装五官**：安全眼扣上、刺绣五官（封口后无法安装）
4. **头身缝合**（或一体钩出）：用身体留的线尾缝 [012]；两层头结构则物理不脱落 [005]
5. **装手臂**：定坐标（第 56 圈 [008] / 头身接缝两侧 [012]）
6. **头发**：发帽固定 → 发片逐条分层缝 → 刘海雕形 [014][005]
7. **服装**：穿上/直接长出 [005]
8. **配件**：帽、耳机、盾牌等最后装 [008]
9. **后处理**：腮红色粉、整形（blocking）、藏线头 [008]

> 规律：**承重与不可逆步骤在前（塞棉、封口、五官），识别性特征在后（头发、服装、配件）**——因为特征层正是可替换、可换色的"差异层"[013]。

## 二、从人物到图解的「信息损失点」

按"人物特征 → 图解能否表达"归纳（主要证据 [007] 淘宝百科、[005] 结构自述、[001] 表达体系、[017] 图片型图解）：

| # | 人物特征 | 图解里的命运 | 语料证据 |
|---|---|---|---|
| 1 | 写实面部（根根分明睫毛、瞳孔渐变、高光） | **降维**：改刺绣或省略；瞳孔只有一对安全眼 | [007]"真人睫毛无法用毛线钩出根根分明效果，通常会改为刺绣或省略" |
| 2 | 表情/微表情 | 只能固化**一种**表情，刺绣针数有限 | [007] 简化五官；[005] sculpted faces 属高级难点 |
| 3 | 头身比例（真人 1:7 → Q 版 1:2~1:3） | **强制重映射**为大头身比，且是卖点而非缺陷 | [007]"大头身比、简化五官…是技术适配的结果，而非设计偷懒" |
| 4 | 发型细节（发丝方向、渐变发色、蓬松度） | 近似为 **发帽+发片**；发色只能分段换色；发量受重量限制（太重头歪） | [014][005]"extra weight in the hair is exactly what tips a chibi head sideways" |
| 5 | 多层服装、接缝、褶皱 | **合并为色块拼接**；褶皱用外半针留针模拟 | [007]"多层铠甲接缝可能合并为色块拼接"；[005][006] |
| 6 | 材质质感（皮肤/金属/皮革/纱） | 全部统一为**线圈纹理**；金属光泽不可表达 | [007]"用线圈堆叠出体积…无法精确复刻细节" |
| 7 | 姿态、动作、透视 | 静态对称站姿；**选图时就要求正面平视、轮廓完整** | [007] 选图建议；[011] "facing the camera with the whole shape visible" |
| 8 | 印花、logo、文字 | 需转像素图（graphgan/十字绣）或省略 | [009] Graphgan 术语；[011] flat chart 独立于玩偶图解 |
| 9 | 精细细节的**尺寸下限** | 由针目尺寸决定（8–14cm 玩偶的最小可辨单元≈1 针），细节在此以下必然丢失 | [013] 8cm/2.25mm；[005] 14cm/3mm 钩 |
| 10 | 颜色渐变/环境色 | 离散为**有限毛线色号 + 换色点**（DMC 映射、yarn-change notes） | [011] "maps DMC colors… where each color changes" |
| 11 | 可动性、悬空结构（独立站立、手臂平举） | PP棉不支撑，除非加铝线骨架（定制时常不含） | [007]"高弹不等于定型" |
| 12 | 图解**文本层本身**的损失 | 中文圈大量图解是**一张 JPG 长图**，无文本可解析；英文图解的装配段精度远低于逐圈段；翻译还会二次省略 | [017] 图片型；[003][014] 装配段简略；[001]"信息不全或表达有省略…影响完成率" |

**结论**：信息损失不是均匀发生的，集中在三处——
1. **连续量 → 离散量**（颜色、比例、纹理被量化到针/色号）；
2. **3D 视觉 → 结构可实现性**（姿态、层次、材质被"能不能钩出来"过滤）；
3. **图解文本层 → 传播介质**（图片化、翻译省略、装配段非形式化）。

这也解释了 [007] 的验收标准：定制行业只要求核对**轮廓比例与配色**，明确放弃像素级还原——因为那部分信息在编译（人物→图解）时已被合法丢弃。

## 三、中外图解表达体系的差异

### 3.1 三分格局（总纲，[001]）

| 体系 | 主流地区 | 载体 | 特点 | 适合人群 |
|---|---|---|---|---|
| **文字类**（written） | 欧美 | 英文句子 + 缩写 | `R1: (sc, inc) x6 (12)`；括号尾带总针数；星号 `*...*` 表重复 [002] | 需懂 sc/inc/dec 术语；靠数针自检 |
| **符号类**（symbol chart） | 日本 | 符号图，以符代织 | 制作繁琐但直观，"以符号表现实际织物" [001]；**符号全球统一，跨语言可读** [009]；多为从右向左、从下向上 [009] | 新手友好，读图不识字 |
| **字母类** | 中国 | X/V/A 象形字母 | `R2: V,3X,3V,3X,2V` [006]；`X=短针 V=加针 A=减针` [015]；多译自外文，**翻译习惯不一、常有省略** [001] | 有玩偶经验者；针法单一的玩偶 |

### 3.2 逐项对比

| 维度 | 英文文字逐圈 | 日式符号图 | 中文字母缩写 |
|---|---|---|---|
| 一句话结构 | 一整圈一个英文句子 | 无句子，图即数据 | 一行为一圈的字母串 |
| 自检机制 | 每圈末尾括号总针数 [002] | 图形与织物直接对照 | 靠圈数与隐含针数（常不标注总数）[006] |
| 术语陷阱 | 美式/英式同名异物（sc 美=短针，英式对应 dc）[009] | 无术语问题 | 音译/自造字母（TM 或 MT 顺序不固定）[001] |
| 信息密度 | 低（冗长） | 高（一次给全部针位） | 中 |
| 传播形态 | 博客 + PDF（Ravelry/Etsy）[002][010] | 书籍/杂志内页 | 微博/堆糖**长图**、微信群转发 [017] |
| 装配说明 | 文字 + "缝到第 56 圈"式坐标 [008] | 结构图 + 符号 | "结构图"与图解并列给出 [015]，常仅配图 |
| 二次损失 | 无 | 无（但抓取工具读不到） | **翻译省略直接降低完成率** [001] |

### 3.3 关键观察

1. **符号是唯一跨语言层**：美英术语互相打架而符号统一（[009]），所以日式符号图是"中立格式"；字母类则是**中国圈自创的第二套中间码**——本质是把符号象形化成 ASCII [001]。
2. **三种体系的可解析性天差地别**：文字逐圈（英文）几乎可直接结构化成 JSON（圈号/针法/计数）；字母类同样可解析（X/V/A 文法极简）；**符号图与图片长图没有文本层**，是自动化分析的主要盲区 [017]。
3. **同一款玩偶三种写法**（[001] 实例）证明：体系差异是**编码层**差异，不改变编织语义——做"人物↔图解"映射时，应先把三种编码归一到统一中间表示（圈/针/计数/部件），再谈人物特征。
4. **表达体系之外的第三维是「分发形态」**：英文=网页逐圈文字，中文=一张图解长图（[017]），这决定了语料采集策略（文本抓取 vs OCR/多模态读图）。
