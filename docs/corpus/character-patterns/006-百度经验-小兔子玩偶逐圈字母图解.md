## 正文

毛线编织玩偶给人一种温暖的感觉，冬天了，给自己编织一个可爱的暖暖的小兔子玩偶吧，挂在包包上，拿在手上玩都是极好的。

**工具/原料**：钩针，毛线，填充棉，钥匙圈

**兔子腿：**

```
R1: 六针辫子针，倒两针钩四针短针，再在一个针目里钩三个短针，再三针短针，一个针目里钩两针短针
R2: V,3X,3V,3X,2V
R3-5: 18X
R6: 5X,4A,5X
R7: 5X,2A,5X
R8: 4X,2A,4X
R9: 3X,2A,3X
R10: 2X,2A,2X
R11: 6X
R12-26: 6X
钩好兔子腿塞入填充棉，同样的钩法钩出两条腿，第二条腿不断线
```

**兔子身体：**

```
R27: 两条腿合并，没断线的腿钩三个锁针，连接第一条腿钩6X，在三个锁针处钩3X，再6X,3X
R28: 2X,V
R29: 24X
R30: V,3X
R31-33: 30X
R34: 钩离自己远的半针30X
R35-44: 30X
R45: A,3X
R46: A,2X（塞入填充棉）
R47: A,X
R48: 6A
钩好后，继续塞入填充棉
```

**脖子：** `R49-51: 6X`

**头：**

```
R52: 6V
R53: 12V
R54: 3X,V
R55: 4X,V
R55-61: 36X
R62: 4X,A
R63: 30X
R64: 3X,A
R65: 24X
R66: 2X,A
R67: 18X（塞入填充棉）
```

## 抓取备注

- 中文「字母类」图解的典型样本：**R=圈，X=短针，V=加针，A=减针**，一行为一圈，括号里偶尔夹中文提示（塞棉）。
- 腿→合并成身体→脖子→头 **不断线连钩** 的顺序，是中文玩偶图解最常见的结构写法（与欧美"分部件后缝合"相对）。
- `R34: 钩离自己远的半针30X`（即 BLO/FLO 留半针）——为后续部件（如裤脚/裙边）预留连接位的典型表达。
- 同站姊妹篇《钩针图解是什么意思》见 015 号文件（X/V/A 含义）。
